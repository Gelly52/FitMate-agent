# 分析本周训练

## 执行步骤

1. 调用 `training_log.query` 查询最近 7 天力量训练记录，参数: {"days": 7, "limit": 50}
2. 调用 `cardio.query` 查询最近 7 天有氧训练记录，参数: {"days": 7, "limit": 50}
3. 调用 `body_metrics.query` 查询最新身体指标，参数: {"limit": 3}
4. 基于返回数据分析以下维度

## 分析维度

### 训练频率
- 本周训练总次数（力量 + 有氧）
- 与上周对比（如有历史数据）
- 是否达到用户目标频率

### 肌群分布
- 各肌群训练次数统计
- 是否存在明显不平衡（某肌群过多/过少）
- 建议补充的肌群

### 训练量趋势
- 力量训练总组数、总重量
- 有氧训练总距离、总时长
- 与近期趋势对比（递增/递减/平台）

### 身体指标变化
- 体重、体脂率变化趋势
- 与训练强度的关联性

## 输出要求

- 用表格呈现训练频率与肌群分布
- 给出 2-3 条基于数据的具体建议（避免空泛鼓励）
- 如发现训练不平衡，明确指出并给出调整方案
