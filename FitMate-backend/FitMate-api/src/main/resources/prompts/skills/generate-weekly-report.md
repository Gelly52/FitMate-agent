# 生成本周周报

## 执行步骤

1. 调用 `training_log.query` 查询最近 7 天力量训练，参数: {"days": 7, "limit": 50}
2. 调用 `cardio.query` 查询最近 7 天有氧训练，参数: {"days": 7, "limit": 50}
3. 调用 `body_metrics.query` 查询最新身体指标，参数: {"limit": 5}
4. 调用 `diet.query` 查询最近 7 天饮食记录，参数: {"days": 7, "limit": 50}
5. 调用 `memory.search` 查询用户训练目标，参数: {"query": "目标 计划"}
6. 整合数据生成本周训练周报

## 周报结构

### 一、本周训练概览
- 训练总次数（力量 + 有氧）
- 总训练时长
- 主要训练肌群分布

### 二、关键数据
- 力量训练：总组数、总训练量（kg）、PR 记录（如有）
- 有氧训练：总距离、总时长、平均配速
- 身体指标：体重变化、体脂率变化

### 三、饮食与营养
- 本周日均热量摄入
- 蛋白质/碳水/脂肪摄入比例
- 与训练目标的匹配度评估

### 四、目标进展
- 对照用户训练目标（减脂/增肌/力量提升）
- 本周进展评估（领先/持平/滞后）

### 五、下周建议
- 基于本周数据给出 2-3 条具体建议
- 如需要调整训练计划，给出方向

## 发送方式

周报生成后，询问用户是否需要发送到邮箱：
- 用户确认发送时，调用 `sendMailMessage` 工具，subject 为"FitMate 训练周报 - {本周日期范围}"
- contentType 用 1（Markdown 格式）
- 如用户未提供邮箱或不需要发送，仅在对话中展示周报

## 输出要求

- 周报使用 Markdown 格式，含表格与列表
- 数据必须基于实际查询结果，不得编造
- 建议要具体可执行，避免空泛表述
