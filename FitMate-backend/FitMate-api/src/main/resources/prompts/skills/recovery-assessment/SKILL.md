# 恢复状态评估

## 执行步骤

1. 调用 `body_metrics.query` 查询最近身体指标，参数: {"limit": 7}
2. 调用 `heart_rate.query` 查询最近心率记录，参数: {"days": 7, "limit": 7}
3. 调用 `training_log.query` 查询最近训练记录，参数: {"days": 14, "limit": 30}
4. 调用 `memory.search` 查询用户历史恢复相关记忆，参数: {"query": "恢复 疲劳 休息"}
5. 基于多维数据综合评估

## 评估维度

### 疲劳水平
- 近 7 天训练频率与强度
- 静息心率变化（升高 >=5 bpm 提示疲劳累积）
- HRV 趋势（下降提示恢复不足）
- 用户自评疲劳等级（身体指标中的 fatigue 字段）

### 恢复状态判定
- **充分恢复**：训练频率合理，静息心率稳定，疲劳自评低
- **轻度疲劳**：连续训练无休息日，或疲劳自评中
- **明显疲劳**：静息心率升高，HRV 下降，疲劳自评高
- **过度训练风险**：多项指标异常，伴随表现下降

### 恢复建议
- 充分恢复：维持当前节奏
- 轻度疲劳：建议安排 1-2 天主动恢复日
- 明显疲劳：建议减少训练量 30-50%，增加睡眠
- 过度训练风险：建议完全休息 3-5 天，必要时就医

## 输出要求

- 先给出恢复状态总评（一句话结论）
- 用列表呈现关键指标数据
- 给出具体的恢复建议（休息天数、训练量调整、睡眠建议）
- 引用用户历史记忆中的恢复特征（如有）
